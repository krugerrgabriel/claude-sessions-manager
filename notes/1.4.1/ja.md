## ✨ ダッシュボードを離れずに変更点を確認

これまで各バージョンのリリースノートは GitHub でしか読めませんでした。今は
サイドバーから、あなたの言語で読めます。

### 新機能

#### 📖 更新情報ボタン

サイドバーの下部にあるボタンで、インストール済みバージョンのノートが開きます。
テキストはアプリに同梱され、言語ごとに 1 ファイルなので、選んだ言語で表示され、
ネットワークがなくても動きます。

更新後に初めてダッシュボードを開いたときはボタンが目立ち、次の再読み込みでは
控えめになり、読み終えると通常の表示に戻ります。

### 🐛 修正

- **更新するとダッシュボードのスタイルが消えることがありました。** ブラウザが
  前のバージョンの CSS を使い続け、強制再読み込みでしか新しい CSS が読み込まれ
  ませんでした。更新時にスタイルシートとスクリプトへバージョン番号を付けるよう
  になり、キャッシュが一度も見たことのないアドレスになります。

### ✨ 仕上げ

- **更新がターミナルを求める場面が減りました。** 以前は `install.sh` に変更が
  あれば、ファイルをコピーするだけの変更でも止まっていました。今は Apache の
  設定そのものが変わったときだけ止まります。root が本当に必要なのはその部分
  です。
- **リリースノートが更新と一緒に届く**ので、次のバージョンのノートを読もうと
  したときには、すでにディスク上にあります。
