## 📋 コピー方法を選べて、ターミナルなしで更新できます

コピーボタンはシェルコマンドを前提としなくなり、更新ボタンは貼り付け用の
コマンドを渡すだけではなくなりました。

### 新着情報

#### 📋 コピー形式の選択

ヘッダーの新しい選択メニューが、コピーボタンがクリップボードに入れる内容を
決めます。3 つの選択肢があり、選んだ内容は保存されます。

- **ターミナルのコマンド** は `claude --resume <id>` を入れます。Claude Code
  を閉じた状態でシェルに貼り付ける用です。
- **Claude 内のコマンド** は `/resume <id>` を入れます。すでに開いている
  Claude Code に貼り付ける用です。
- **毎回尋ねる** はコピーのたびに選択画面を開き、そのセッションの実際の
  コマンドを表示します。

既定はターミナルのコマンドなので、変更するまで挙動は変わりません。

#### ⚡ ワンクリック自動更新

更新ボタンはコマンドをコピーするのではなく、更新そのものを適用するように
なりました。クリックすると pull し、ファイルを入れ替え、新しいバージョンで
ページが再読み込みされます。ターミナルも `sudo` も不要です。

`install.sh` 自体が変わったリリースでは Apache の設定も変わっている可能性が
あり、それには root が必要です。その場合は更新を止めて、何が起きたかを説明
するモーダルとコピーできるコマンドを表示します。クローンに未コミットの変更が
ある場合も同じモーダルが出ます。あなたの編集が破棄されることはありません。

#### 🔒 localhost のみ

**このダッシュボードは認証なしでローカルネットワークから到達可能でした。**
同じ Wi-Fi にいる誰もが、すべてのセッションの名前、プレビュー、プロジェクト
パス、ブランチを読め、セッションファイルを削除できました。現在は localhost
のみで待ち受けます。**これを適用するのはインストーラの再実行です。**

### 🐛 修正

- **プロジェクト間のセッション移動でセッションを失うことがありました。**
  Claude Code はパスの英数字以外の文字をすべてダッシュに変えますが、
  バックエンドは区切り文字だけを置き換えていました。`_`、`.`、空白、
  アクセント記号を含むパスのプロジェクトへ移動したセッションは再開できなく
  なっていました。
- **壊れた `metadata.json` が、名前・メモ・お気に入りを黙って消していました。**
  API は書き込みを拒否して理由を伝え、ファイルはそのまま残します。
- **正規表現の文字を含むプロジェクト名で画面が真っ白になりました。**
- **コピー時にカードが跳ねていました。** その状態でセッション ID が隠れて
  いたためです。

### ✨ 仕上げ

- コピー形式・並べ替え・言語のネイティブセレクトを**独自のドロップダウン**に
  置き換えました。キーボード操作に完全対応し、幅は一定です。
- **`backdrop-filter` を削除。** 誰も求めていないぼかしのために、固定ヘッダー
  をスクロールのたびに再描画していました。
- **セッション ID を省略せず表示。** 固定 8 文字ではなくなりました。
- **7 言語すべてでドキュメントを更新。**
