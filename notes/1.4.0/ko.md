## 📋 복사 방식을 고르고, 터미널 없이 업데이트하세요

복사 버튼은 더 이상 셸 명령어를 원한다고 단정하지 않고, 업데이트 버튼은 더
이상 붙여넣을 명령어만 건네지 않습니다.

### 새로운 기능

#### 📋 복사 형식 선택기

헤더의 새 선택기가 복사 버튼이 클립보드에 담을 내용을 정합니다. 세 가지
선택지가 있고, 선택은 저장됩니다.

- **터미널 명령어** 는 `claude --resume <id>` 를 담습니다. Claude Code가 닫힌
  상태에서 셸에 붙여넣는 용도입니다.
- **Claude 안에서 쓰는 명령어** 는 `/resume <id>` 를 담습니다. 이미 열려 있는
  Claude Code에 붙여넣는 용도입니다.
- **항상 물어보기** 는 복사할 때마다 선택창을 열어 해당 세션의 실제 명령어를
  보여줍니다.

기본값은 터미널 명령어라서, 직접 바꾸기 전까지는 달라지는 것이 없습니다.

#### ⚡ 클릭 한 번으로 업데이트

업데이트 버튼이 이제 명령어를 복사하는 대신 업데이트를 직접 적용합니다.
클릭하면 pull하고, 파일을 교체하고, 새 버전으로 페이지가 다시 로드됩니다.
터미널도 `sudo` 도 필요 없습니다.

릴리스가 `install.sh` 자체를 바꾼 경우에는 Apache 설정도 함께 바뀌었을 수
있고, 그건 root 권한이 필요합니다. 그럴 때는 업데이트를 멈추고 무슨 일이
있었는지 설명하는 모달과 복사할 수 있는 명령어를 보여줍니다. 클론에 커밋하지
않은 작업이 있을 때도 같은 모달이 나옵니다. 여러분의 수정 사항은 절대
버려지지 않습니다.

#### 🔒 localhost 전용

**이 대시보드는 인증 없이 로컬 네트워크에서 접근할 수 있었습니다.** 같은
Wi-Fi에 있는 누구나 모든 세션의 이름, 미리보기, 프로젝트 경로, 브랜치를 읽을
수 있었고 세션 파일을 삭제할 수도 있었습니다. 이제 localhost에서만 서비스
합니다. **설치 스크립트를 다시 실행해야 이것이 적용됩니다.**

### 🐛 수정

- **프로젝트 간 세션 이동에서 세션을 잃을 수 있었습니다.** Claude Code는 경로의
  영숫자가 아닌 모든 문자를 대시로 바꾸는데, 백엔드는 구분자만 바꿨습니다.
  경로에 `_`, `.`, 공백, 악센트가 있는 프로젝트로 옮긴 세션은 재개할 수 없게
  되었습니다.
- **손상된 `metadata.json` 이 모든 이름, 메모, 즐겨찾기를 조용히 지웠습니다.**
  이제 API가 쓰기를 거부하고 이유를 알려주며, 파일은 그대로 둡니다.
- **정규식 문자가 들어간 프로젝트 이름에서 화면이 비었습니다.**
- **복사할 때 카드가 튀었습니다.** 그 상태에서 세션 id가 숨겨졌기 때문입니다.

### ✨ 다듬기

- 복사 형식, 정렬, 언어의 네이티브 select를 **직접 만든 드롭다운**으로
  교체했습니다. 키보드를 완전히 지원하고 너비가 일정합니다.
- **`backdrop-filter` 제거.** 아무도 원하지 않은 블러 하나 때문에 스크롤할
  때마다 고정 헤더를 다시 그리고 있었습니다.
- **세션 id를 전부 표시합니다.** 고정 8자가 아닙니다.
- **7개 언어 문서를 모두 최신화했습니다.**
