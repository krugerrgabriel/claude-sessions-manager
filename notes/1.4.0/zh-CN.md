## 📋 自选复制方式，更新无需终端

复制按钮不再假定你要的是 shell 命令，更新按钮也不再只是给你一条命令去粘贴。

### 更新内容

#### 📋 复制格式选择器

顶栏新增的选择器决定复制按钮往剪贴板里放什么。三个选项，选择会被保存：

- **终端命令** 放入 `claude --resume <id>`，用于在 Claude Code 关闭时粘贴到
  shell。
- **Claude 内命令** 放入 `/resume <id>`，用于粘贴到已经打开的 Claude Code。
- **每次询问** 在每次复制时打开选择框，显示该会话的真实命令。

默认是终端命令，所以在你另行选择之前一切照旧。

#### ⚡ 一键自动更新

更新按钮现在直接应用更新，而不是复制命令。点击后它会拉取代码、替换文件，
页面在新版本上重新加载。不用终端，也不用 `sudo`。

当某个版本改动了 `install.sh` 本身时，Apache 配置也可能一起变了，那需要
root 权限。此时更新会停下，弹窗说明发生了什么，并附上可复制的命令。如果你的
克隆有未提交的修改，也会出现同样的弹窗，因为你的改动永远不会被丢弃。

#### 🔒 仅限 localhost

**这个面板此前可以从你的局域网访问，且没有任何认证。**同一个 Wi-Fi 下的任何
人都能读到所有会话的名称、预览、项目路径和分支，还能删除会话文件。现在它只在
localhost 上提供服务。**重新运行安装脚本才会应用这一点。**

### 🐛 修复

- **在项目间移动会话可能会弄丢它。** Claude Code 会把路径中每一个非字母数字
  字符都变成短横线，而不只是分隔符，但后端只替换了分隔符。移动到路径包含
  `_`、`.`、空格或重音字符的项目后，会话就无法恢复了。
- **损坏的 `metadata.json` 会静默清空所有名称、备注和收藏。** 现在 API 会拒绝
  写入并给出提示，文件保持原样。
- **项目名包含正则字符会导致白屏。**
- **复制时卡片会跳动**，因为那个状态下会话 id 被隐藏了。

### ✨ 打磨

- 复制格式、排序和语言的原生 select 换成了**自定义下拉框**，完整支持键盘操作，
  宽度恒定。
- **移除了 `backdrop-filter`。** 它为了一个没人要求的模糊效果，在每一帧滚动中
  重绘固定顶栏。
- **会话 id 完整显示**，不再固定 8 个字符。
- **7 种语言的文档全部补齐。**
